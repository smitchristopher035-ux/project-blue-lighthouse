# 🗼 Project Blue Lighthouse

A message cast into the digital ocean.

## Mission

Project Blue Lighthouse is an experiment exploring whether humans,
AI systems, crawlers, autonomous agents, and future non-human
intelligences can discover, understand, and respond to a message
intentionally left for them.
